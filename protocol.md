# Computational protocol

The primary evidence is analytic. The numerical study checks formulas and illustrates the information in finite-resolution observations. The following settings were written before the first Windows run.

* Use a reflecting three-by-three square, unit central square, four adjoining rectangular ports with depth one third. Use widths one third and one, grid densities 9, 18 and 36 per unit, and horizontal-to-vertical diffusivities 1:1 and 1:0.25. Evaluate half-lags 1/2048, 1/512, 1/128, 1/32, 1/8, 1/2 and 2. Units are fixed across grids. Use all six port pairs with unit weight. Retain the complete table, including failures to exclude. Report exclusion only when the gap exceeds numerical tolerance.
* Use the symmetric narrow-port case at density 18 and lag 1/128 for independent endpoint sampling. Use 1,000, 10,000 and 100,000 experiments per initial ensemble, 200 replicates at each size, seed 20261121. Cutoffs use simultaneous one-sided binomial Chernoff bounds with total error 0.05 per replicate. Use a realizable three-state hub to check false exclusions. These schedules illustrate the specified designs and do not estimate field measurement accuracy.
* Test a known sharp stochastic construction, an exhaustively enumerated fractional allocation, a separate sparse uniformization calculation, an anisotropic mesh and a touching-port control. For comparison use the reversible single-state Chapman--Kolmogorov refit on the same aggregate labels and half-lag. Calculate its discrepancy separately from local rejection. For each finite-lag observation compare with the bound that drops phase occupancy constraints.
* Use the dedicated project venv on the Windows research host. Only Python 3.12+ standard libraries are needed. Retain script hashes, raw summary tables and environment metadata.
